# Голосовой календарь

Школьный Android-прототип: распознаёт русскую речь на устройстве с Vosk, выделяет дату, время и название события и открывает системную форму календаря с заполненными полями.

## Пример

Фраза: «Завтра в три встреча с врачом»  
Результат: «Встреча с врачом», завтра в 15:00. Для времени без уточнения часы с 1 до 7 трактуются как после полудня; добавьте «утра» или «вечера», если нужен другой вариант. Перед переходом в календарь приложение показывает результат для проверки.

## Что поддерживает первая версия

- Офлайн-распознавание русской речи с небольшой моделью Vosk.
- Ручной ввод или исправление распознанного текста.
- Даты «сегодня», «завтра», «послезавтра», «12 мая» и «12.05.2027».
- Время «в 15:30», «в 6 вечера» и несколько простых числительных, например «в три» (по умолчанию 15:00).
- Продолжительность события по умолчанию — один час. Если время не задано, создаётся событие на весь день.
- Передача данных в календарь Android через его системную форму. Пользователь проверяет запись и нажимает «Сохранить».

Парсер намеренно ограничен перечисленными форматами; произвольные фразы могут быть разобраны неверно. Модель распознаёт речь, но не понимает смысл события сама по себе. В приложении остаётся возможность исправить результат.

## Сборка и запуск

Откройте проект в Android Studio и соберите конфигурацию `app`. Для сборки нужны Android SDK 37 и JDK 17 или новее. При первом запуске приложение распакует включённую модель (примерно 45 МБ) во внутреннюю память телефона; запуск распознавания возможен после подготовки модели. После этого распознавание работает без сети.

Для записи речи потребуется разрешение на микрофон. Доступ к календарю приложению не нужен: оно передаёт название и время через системную форму создания события.
